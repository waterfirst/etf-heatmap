# 📈 ETF 모멘텀 히트맵

공공데이터포털(한국거래소) **ETF 시세 확정 일봉** 데이터로 ETF의 모멘텀 순위와 순위 변동을
히트맵(트리맵)으로 보여주는 단일 페이지 웹앱입니다. PC에서 매일 확인하는 용도로 만들어졌습니다.

- **크기 = 모멘텀 점수** (가중 수익률 합)
- **색상 = 순위 상승폭** (빨강 ▲ 상승 / 파랑 ▼ 하락 / 보라 = 신규 진입)
- 셀 클릭 → 해당 ETF의 **가격·거래량 / 모멘텀 / 스토캐스틱 / RSI / MACD** 상세 차트
- 상단에 **삼성전자·SK하이닉스** 시세 (장중 실시간 / 장 마감 시 종가)
- 가중치·필터·표시 개수·순위 비교기간을 화면에서 직접 조절
- **레버리지 제외** 토글
- 일별 데이터 **CSV 내보내기**

> 이 앱이 보여주는 ETF 데이터는 **확정 일봉**(전일/직전 거래일 종가 기준)입니다.
> 장중 실시간이 아닙니다. 상단 삼성전자/SK하이닉스 티커만 네이버 시세로 실시간을 시도합니다.

---

## 실행 방법 (권장: 로컬 서버)

공공데이터포털 API는 **브라우저의 직접 호출을 CORS로 차단**합니다.
그래서 `index.html`을 더블클릭(`file://`)하면 데이터 호출 시 **`Failed to fetch`** 오류가 납니다.
이건 브라우저 보안 정책이라 HTML만으로는 우회할 수 없고, **로컬 서버(파이썬 프록시)** 가 필요합니다.

### Windows
1. 이 폴더에서 **`start.bat`** 더블클릭
2. 자동으로 `http://localhost:8765` 가 브라우저에 열림
3. 서비스키 입력 → **[모멘텀 계산하기]**

`start.bat`은 `etf_server.py`를 실행합니다. 이 서버가
공공데이터포털·네이버 시세 요청을 **서버 측에서 대신 호출**해 CORS를 우회합니다.

### 직접 실행
```bash
python etf_server.py
```
파이썬 3만 있으면 별도 패키지 설치가 필요 없습니다(표준 라이브러리만 사용).

## 서비스키 (중요 · 보안)

- 공공데이터포털 → "금융위원회_증권상품시세정보" / "금융위원회_주식시세정보" 활용신청 → **Decoding 키** 사용
- 키는 화면에서 입력하며 **브라우저 localStorage 에만 저장**됩니다. 코드에는 들어가지 않습니다.
- ⚠️ **API 키를 공개 GitHub 저장소나 코드에 절대 넣지 마세요.**
  공개되면 누구나 사용할 수 있어 일일 호출 한도가 소진되거나 키가 정지될 수 있습니다.

## GitHub Pages 배포에 대해 (꼭 읽어주세요)

`index.html`을 올리면 페이지 **화면 자체는** `https://<사용자>.github.io/<레포>/` 에서 뜹니다.
**그러나 데이터는 안 나올 가능성이 높습니다.** 이유:

1. **CORS** — 공공데이터포털은 브라우저 직접 호출을 막습니다. GitHub Pages는 **정적 호스팅**이라
   파이썬 프록시(`etf_server.py`)를 **실행할 수 없습니다.** 즉 로컬에서 쓰던 CORS 우회 수단이 Pages엔 없습니다.
2. **파이썬 파일은 실행되지 않습니다** — `etf_server.py`는 Pages에서 그냥 소스 텍스트로만 올라갑니다.
3. **키 노출** — 데이터를 받으려고 키를 코드에 넣으면 공개 저장소에 그대로 노출됩니다.

### 결론
- **"매일 PC에서 확인"이 목적이면 GitHub Pages가 아니라 로컬 `start.bat` 사용이 맞습니다.**
- GitHub에는 **코드 백업·공유 용도**로 올리되 **키는 절대 포함하지 마세요.**
- 정말 웹(URL)로 배포하고 싶다면, 프록시를 **서버(예: Google Cloud Run, Render, Fly.io 등)** 에
  올려야 합니다. (참고로 원본 ETF 모멘텀 계산기도 Cloud Run 서버 방식입니다.)

## 모멘텀 계산 방식

각 기간 수익률에 가중치를 곱해 합산합니다(기본값 화면 기준):

```
모멘텀 점수 = 0·(1주) + 0·(2주) + 12·(1개월) + 4·(3개월) + 2·(6개월)   (수익률 %)
```

- 기준일은 항상 **오늘**로 설정되며, 휴일이면 **직전 거래일**로 자동 보정됩니다.
- **순위 변동**은 "순위 비교기간(기본 7일)" 전 시점의 모멘텀 순위와 비교해 계산합니다.
- 받아온 시세는 브라우저에 캐시되어, 다음날엔 새 날짜만 추가로 받아 빠르게 동작합니다.
